# Charte des objets Parcel Kings

Tous les objets utilisent un cadrage carré, un fond réellement transparent et
une vue de trois quarts avant. L'objet doit être entier, centré et entouré d'une
marge régulière.

## Prompt de référence

```text

Asset type: premium collectible object for Parcel Kings web game, transparent PNG cutout
Primary request: [DESCRIPTION PRÉCISE DE L'OBJET]
Scene/backdrop: genuinely transparent background, isolated object only
Style/medium: high-end stylized 3D product render, coherent premium video game inventory asset
Composition/framing: single complete object centered, three-quarter front view, generous transparent margin, square framing, no cropping
Lighting/mood: dramatic soft studio rim lighting, [COULEUR SELON LA RARETÉ], crisp silhouette
Materials/textures: [MATÉRIAUX], extremely detailed and tactile

```

## Lumière par rareté

- Normal : blanc neutre ou gris argenté.
- Commun : bleu froid.
- Rare : violet.
- Légendaire : orange ou ambre.
- Unique : or intense avec reflets ponctuels subtils.

Les images finales sont des PNG RGBA de 1254 × 1254 pixels.
